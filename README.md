# NotebookLM Clone

Aplicación web inspirada en Google NotebookLM: cuadernos, fuentes, chat y Studio.
Estado: **Fase 4 completada** (backend e integración con la interfaz). Ver [docs/setup.md](docs/setup.md).

Stack: React + TypeScript + Vite + Tailwind v4 · FastAPI + SQLAlchemy + Alembic · PostgreSQL + pgvector.
La IA usa un proveedor *mock* hasta integrar uno real.
